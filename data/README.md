# Data

This folder contains `book.json.br` — the Brotli-compressed data file that the
`@open-and-async/mcp` server reads to answer tool calls. It holds the book's
already-public summaries (outline, chapter TL;DRs, key takeaways, taglines) and
reviewed, paraphrased framework material from *[Open and Async](https://open-and-async.com)*
by Ben Balter. It does **not** contain the book's prose.
